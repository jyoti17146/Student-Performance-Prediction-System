
# Student Performance Prediction Using Machine Learning

## 1. Project Overview
This project predicts student academic performance using Machine Learning techniques.

It analyzes student-related data such as study hours, attendance, previous marks, and other academic factors to predict student performance.

## 2. Objectives
- To predict student academic performance.
- To analyze the factors affecting student results.
- To visualize student performance using graphs.
- To help students improve their academic performance.

## 3. Technologies Used
- Python
- Machine Learning
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Streamlit

## 5. Installation

First, clone or download this project.

Install the required libraries:

```bash
pip install -r requirements.txt
```

## 6. How to Run the Project

Run the following command in the terminal:

```bash
streamlit run app.py
```

The application will open in your web browser.

## 7. Features
- Student data analysis
- Performance prediction
- Data visualization
- Machine Learning model
- Interactive web interface

## 8. Expected Output
The application predicts student performance based on the input data and displays the results through an interactive dashboard.
